VoxAgent Studio

Privacy Policy

Last updated: 7 November 2026

Who uses this app

VoxAgent Studio is a private production tool used only by the team that runs the VoxAgent YouTube channel. It is not offered to the public and has no other users.

What it accesses

With the channel manager's permission, given through Google's sign-in screen, the app uses the YouTube Data API to:

  • upload finished VoxAgent episodes to the VoxAgent channel as private videos,
  • set the thumbnail of those videos,
  • create and update the channel's own playlists (for example "Season 1.0" and "Season 2.0").

It does not read, store or process viewers' data, comments, subscribers' personal information or any other Google account data.

How credentials are kept

The access token issued by Google is stored only as an encrypted secret in the team's private build system and is used only to perform the actions above. It is never shared with third parties or sold.

Google API Services

VoxAgent Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube use is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent through the contact details on the VoxAgent YouTube channel.
